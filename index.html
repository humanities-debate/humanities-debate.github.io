프로그램은 무료 개인·비상업용입니다. AI 토론·피드백 이용에는 적격 본인 ChatGPT Plus 또는 Pro 구독이 필요합니다. 설치한 앱에서 공식 Continue with ChatGPT 로그인과 구독 사용 동의를 진행합니다. 개발자의 API 키를 공유받거나 별도 API 키를 입력하는 방식이 아닙니다.

무료·Go 계정은 지원 미검증입니다. Plus/Pro도 계정·구독·작업공간의 이용 자격과 사용량 제한이 적용됩니다. 무제한 사용이나 모든 계정의 이용을 보장하지 않습니다.

AI 토론·분석 내용은 OpenAI로 전송됩니다. Chrome 음성 인식은 온라인 음성 서비스를 사용할 수 있습니다. 홈페이지에서는 로그인이나 마이크 녹음을 진행하지 않습니다.
